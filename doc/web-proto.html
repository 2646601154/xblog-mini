Vue 3 Composition API 完全指南：从入门到精通

👤 技术小熊 📅 2026-04-25 👁 1.2k 阅读 💬 28 评论

什么是 Composition API？

Composition API 是 Vue 3 引入的一种新的编写组件逻辑的方式。它允许我们使用导入的函数来组织组件逻辑，而不是依赖于选项对象。这种方式提供了更好的逻辑复用性、更灵活的代码组织，以及更好的 TypeScript 支持。

"Composition API 是 Vue 3 最强大的特性之一，它让我们能够以一种更灵活的方式组织组件代码。"

setup 函数基础

setup 是 Composition API 的入口点，它在组件实例创建之前执行，在 beforeCreate 钩子之前被调用。这意味着在 setup 中你还不能使用 this，因为实例还没有创建。

响应式系统

Vue 3 提供了两种创建响应式数据的方式：ref 和 reactive。

  • ref：用于创建基本类型的响应式数据，也可以用于对象类型
  • reactive：用于创建对象或数组的响应式引用
  • computed：创建计算属性
  • watch：监听响应式数据的变化

生命周期钩子

在 Composition API 中，生命周期钩子可以通过 onXxx 函数来调用：

import { onMounted, onUpdated, onUnmounted } from 'vue'

onMounted(() => {
  console.log('组件挂载完成')
})

onUpdated(() => {
  console.log('组件更新')
})

onUnmounted(() => {
  console.log('组件卸载')
})

实际应用案例

让我们通过一个实际的搜索功能来展示 Composition API 的用法：

// useSearch.js
import { ref, watch } from 'vue'
import { fetchSearchResults } from '@/api/search'

export function useSearch() {
  const query = ref('')
  const results = ref([])
  const loading = ref(false)

  watch(query, async (newQuery) => {
    if (!newQuery) {
      results.value = []
      return
    }
    loading.value = true
    results.value = await fetchSearchResults(newQuery)
    loading.value = false
  })

  return { query, results, loading }
}

这个自定义 Hook 可以轻松地在多个组件中复用，极大地提高了代码的可维护性。
