# blog-web 配色设计

**主题**: Lavender（薰衣草紫）  
**设计方向**: 柔和、现代、专业

---

## 主色调 (Primary)

| Token | 色值 | 预览 | 用途 |
|-------|------|------|------|
| `--color-primary` | `#8B5CF6` | 🟣 | 主按钮、链接、激活态 |
| `--color-primary-light` | `#A78BFA` | 🟣 | hover 边框、浅色强调 |
| `--color-primary-dark` | `#7C3AED` | 🟣 | 按钮按下态、深色强调 |
| `--color-primary-50` | `#F5F3FF` | ⬜ | 浅紫背景、hover 底色 |
| `--color-primary-100` | `#EDE9FE` | ⬜ | 激活态背景、标签背景 |

## 背景色 (Background)

| Token | 色值 | 预览 | 用途 |
|-------|------|------|------|
| `--bg-page` | `#FAFAFA` | ⬜ | 页面底色 |
| `--bg-surface` | `#FFFFFF` | ⬜ | 卡片、header、模态框 |
| `--bg-elevated` | `#F9F9FB` | ⬜ | 悬浮层、次要区块背景 |

## 文字色 (Text)

| Token | 色值 | 预览 | 用途 |
|-------|------|------|------|
| `--text-primary` | `#1E1B4B` | 深紫黑 | 标题、正文主文字 |
| `--text-secondary` | `#6B7280` | 灰色 | 次要文字、描述 |
| `--text-muted` | `#9CA3AF` | 浅灰 | 占位符、辅助信息 |

## 边框色 (Border)

| Token | 色值 | 用途 |
|-------|------|------|
| `--border-light` | `#E5E7EB` | input 默认边框、分割线 |
| `--border-medium` | `#D1D5DB` | 较深边框 |

---

## 阴影 (Shadow)

> 所有阴影带薰衣草色调，营造柔和氛围。

| Token | 值 | 用途 |
|-------|-----|------|
| `--shadow-sm` | `0 1px 3px rgba(139, 92, 246, 0.06)` | 轻微阴影 |
| `--shadow-md` | `0 4px 16px rgba(139, 92, 246, 0.08)` | 卡片、组件默认 |
| `--shadow-lg` | `0 8px 32px rgba(139, 92, 246, 0.12)` | 弹窗、下拉菜单 |
| `--shadow-hover` | `0 12px 40px rgba(139, 92, 246, 0.16)` | 卡片 hover 抬起 |
